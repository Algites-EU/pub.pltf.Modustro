# Modustro Modeler — CFR Profile (Draft)

Modeler applies the shared [`Modustro CFR`](../../common/cfr/specs/Modustro-CFR-Standard.md) to DSL models and persisted model structures.

Modeler-specific rules to define: DSL element and Def/Ref identities; containment, move and inheritance semantics; references across files/modules; ordered DSL elements; semantic validation after merging; model editing and conflict-resolution UI integration. Generic clocks, merge algorithms, serialization and audit history belong to the common CFR standard.
