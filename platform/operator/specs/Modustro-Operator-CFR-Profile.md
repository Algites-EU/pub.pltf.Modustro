# Modustro Operator — CFR Profile (Draft)

Operator applies the shared [`Modustro CFR`](../../common/cfr/specs/Modustro-CFR-Standard.md) to version-controlled configuration, environments, deployment descriptions and orchestration plans.

Operator-specific rules to define: configuration identities; user/role authorization; validation of cross-service constraints; conflict review and approvals; immutable target revision; and reconciliation against running state. A structurally convergent merge **must not** automatically deploy: approval, authorization and runtime preflight remain separate requirements.

**Status:** Boundary placeholder; not an implemented orchestration or execution contract.
